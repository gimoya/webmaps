GPS Chaser

GPS Chaser in a nutshell: Each rider in a big group ride / training uses the smartphone GPS sensor to track the ride and be visible to all other riders or viewers of that ride!

Riders & viewers

  1. Install first: Add Chaser to your home screen (iOS Safari Share → Add to Home Screen, or Android Install app). Open from that icon — normal browser tabs are blocked (admins with #admin=… can use the browser).
  2. Open the event link you were given, e.g. …/chaser/?event=your-event&mode=viewing.
  3. Push notifications: on the event page, tap the circled ! next to Share to enable (OS permission prompt). Lock/unlock and chat go to everyone with alerts on. Tap ! again to turn off for this app.
  4. Choose Viewer to watch, or Rider (same as hitting the bike button later) to ride.
  5. For tracking: Enter a unique name/alias → Start Ride / Resume. Allow GPS when prompted (only on that tap). Keep internet when logging!
  6. While the page is open and unlocked, track points of your ride will be written. Refresh or lock stops logging until you resume - always (!) use the same alias. Important (!) - Do not reuse someone else’s alias — you would write into their trace!
  7. When finished: Stop tracking. Caution (!): That alias cannot start again on this event. Stop if you want your ranking fixed and locked on the event's route.
  8. Chat: with the panel faded, the bottom-center stack (chat above ⓘ) opens the event message stream. While tracking you can send short text and/or a camera photo (compressed under 100 KB).
  9. Replay: under the bike button — play / pause / stop (shown when riders exist) gives a fast-forward replay of all rides. Helicopter button: 3D course flyover when a GPX is loaded.

Event Creation / Admins

  1. Buy an admin code on Ko-fi (or get one from the developer).
  2. After purchase, check the Chaser email from office@tiroltrailhead.com (spam too) for your 5-character token and personal claim link - you can get your the token only with that email. Ko-fi’s own “Go to your items” button opens only reminder page!
  3. Keep that token. You need it to create the event and later for admin (GPX upload, clear traces, delete riders).
  4. Create: install Chaser, enter your token in the create form. That token is bound to the event permanently.
  5. On the event page as admin: upload GPX, clear traces, delete riders. Share riders/viewers a link without your admin token.
Admins can control the app in normal browser via URL hashes...

Only if you open Chaser in a normal browser tab instead of the installed app.

  • Create / admin unlock: …/chaser/#admin=YOURCODE
  • Admin bookmark: ?event=id&mode=viewing#admin=YOURCODE — never share that full URL.
  • Share: ?event=id&mode=viewing or mode=tracking (no #admin=).
  • Simulation: add &simulation=1 to walk the GPX instead of GPS.
