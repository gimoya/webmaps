Chaser

Riders & viewers

  1. Open the event link you were given (if you look into the web address, you'll see that #hash starts with the event id), e.g. ../chaser/..#your-event.
  2. Choose Viewer to watch, or Rider (same as hitting the bike button later) to ride.
  3. For tracking: Enter a unique name/alias → Start Ride / Resume. Allow GPS and keep internet connected.
  4. While the page is open and unlocked track points are written. Refresh or lock stops logging until you resume - always (!) use the same alias.< Do not reuse someone else’s alias — you would write into their trace.
  5. When finished: Stop tracking. Caution (!): That alias cannot start again on this event. Stop if you want your place locked on a ranked route.
  6. Replay: use the replay control under the bike button to watch a fastfowrd replay of all rides.

Event Creation / Admins

  1. Buy an admin code on Ko-fi (or get one from the developer).
  2. After purchase, open the claim page (should auto-open, but you'll also have it in your confirmation message) and enter the email you used at checkout to reveal your 5-character token. Lost it later? Same claim link + email recovers it anytime. If you bought more than once, all codes for that email are listed (newest first).
  3. Keep that token. You need it to create the event and later for admin (GPX upload, clear traces, delete riders).
  4. Create: open …/chaser/..#admin=YOURCODE, then put name code to the form that opened up, to create and event. Once you have created an event using up one token, that code-token is bound to that event permanently!
  5. You best bookmark the URL including your hash for the event event-id and the admin hash #admin=YOURCODE. NEVER EVER share the address with your admin code publicly!
  6. On that bookmark: On the Chaser Page you can upload GPX, clear all traces, delete a rider.
  7. The internet address you share with everyone else - riders and viewers should contain: #event-id#viewing or #event-id#riding but never ever the hash admin=YOURCODE.
  8. Simulation: as admin you can run a rider simulation by attaching the hash #simulation to the web address. If you now start a Ride / tracking session from your device, the app wont log the devices GPS signal but simply travel along the uploaded gpx route with random speed between 10 and 25 km/h until the end.
