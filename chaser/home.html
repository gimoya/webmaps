Riders & viewers

  1. Open the event link you were given (hash starts with the event id), e.g. #your-event#viewing.
  2. Choose Viewer to watch, or Rider / the bike button to ride.
  3. Enter a unique name/alias → Start Ride / Resume. Allow GPS.
  4. Keep the page open and unlocked while riding. Refresh or lock stops logging until you resume with the same alias.
  5. Do not reuse someone else’s alias — you would write into their trace.
  6. When finished: Stop tracking. That alias cannot start again on this event. Stop if you want your place locked on a ranked route.
  7. Replay (viewer): use the play control under the bike button.

Event admins

  1. Get a pool admin code from the developer (or use master if you have it).
  2. Create: open …/chaser/#admin=YOURCODE → name + code → Create event.
  3. Bookmark #event-id#…#admin=YOURCODE for that event.
  4. On that bookmark: upload GPX, clear all traces, delete a rider.
  5. Share with everyone else: #event-id#viewing (no admin=).
