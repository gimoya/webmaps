Admin usage

How to run your own Chaser event from the app, and what to do during and after the day. Create needs a pool admin code from the developer (or the master password). After create, keep #admin=<your-code> in the URL for GPX upload and clear traces.

1. Make your own event

Get a code

  1. Ask the developer for one unused 5-character pool code.
  2. That code is single-use for create: once you create an event with it, it leaves the pool and sticks to that event forever.

Open the create form

  1. Open the Chaser page.
  2. Add #admin to the URL (or #admin=YOURCODE) and load.
  3. In the event picker you should see New event name and Admin code.

Create the event

  1. Type a clear display name (race / trail day / club run).
  2. Paste the pool code into Admin code.
  3. Click Create event.
  4. Chaser builds a short id from the name. The URL becomes something like #el-camino-2026#viewing#admin=YOURCODE.
  5. Bookmark that full URL (including admin=). Riders get a share link without admin=.
You can do this in the app Create with a pool code, stay on the admin URL for course upload and clear. Switching events: click GPS Chaser in the panel header (admin controls only stay if the code matches that event, or you use master).

Add the course (optional but usual)

  1. Stay on the event with #admin=YOURCODE in the hash.
  2. Use the map upload control and pick a .gpx file (max ~1 MB after thinning).
  3. Upload overwrites that event’s course. Everyone on the same event sees it.
Needs developer / Firebase console Pool seed / reseed when codes run out, master password, renaming event id, deleting an event tree, or attaching a code to a legacy event without one.

2. During and after the event

Before start

  • Share the viewer URL (event id, no admin=).
  • Keep your admin URL private.
  • Confirm the course on a second device.
  • Remind riders: unique alias, keep the tab open, Stop tracking when finished if placement matters.

During

  • Watch as Viewer on a normal link, or admin on your admin link.
  • Clear all traces only with matching admin= (or master). Irreversible for that event.
You can do this in the app Upload/replace GPX, clear traces, switch events, view and replay — with the right admin code in the URL.

After

  • Leave the public event URL as an archive.
  • Next year: create a new event with a fresh pool code.
Needs developer / Firebase console
  • Export traces or GPX
  • Delete one rider session / edit points
  • Delete the whole event tree
  • Reseed adminConfig/current.unusedCodes
  • Rules, billing, project access

Quick checklist

  1. Get a pool code from the developer
  2. #admin → name + code → create → bookmark #…#admin=code
  3. Upload course GPX
  4. Share viewer URL (no admin token)
  5. Empty pool or deeper DB work → contact developer
