    Alias
    The name you enter is the identity used. You will find the alias on your trace in the map and in the list of tracked users in the panel. Always use your own unique alias - using an alias someone else is already tracking can corrupt their trace.
    No tracking
    A fresh webpage load, a browser refresh, or closing the webpage stops this device/browser from tracing your GPS. However,
    Stale signal & screen lock
    A point is stored about every 10 seconds. If no new point is stored for more than 20 seconds, because the phone was locked, the browser was closed or refreshed or you lost signal, then the trace with the last know position will still be on the map but it will ask you to 'Resume or stop tracing using your alias!' in the list of traced aliases. You can continue or stop your trace by typing your alias and hitting the button.
    Start/Resume/Stop
    With no active trace, 'Start' will start a new one for the given alias. If that alias already has an active trace, 'Resume' continues it from the current browser's position. Using 'Stop' for a given alias is the way to end the tracing completely and remove the alias from the list.
