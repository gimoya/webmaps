    Alias
    The name you enter is the only identity. One alias has one active trace. Using an alias someone else is already tracking can corrupt their signal: Resume adds your points to their line, and Stop old & start new ends their trace.
    No tracking on this page
    A fresh load, a refresh, or leaving the page stops this browser from writing points. The trace stays on the map until it is stopped. Stop sharing is only shown while this page is writing.
    Start/Resume Sharing
    With no active trace, this starts a new one for the given alias. If the used alias is already taken for an active trace, resuming will continue this trace with this device's signal. Starting a new trace stops the old active trace for this alias.
    Stop sharing
    Ends every active trace for that alias. Completed traces stay stored and disappear from the live map.
    Stale signal
    A point is stored about every 10 seconds, even if you have not moved. If no new point is stored for more than 20 seconds, because the browser was closed or refreshed or you lost signal, then it says 'Please Resume sharing for the alias!'
