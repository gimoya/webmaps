Open track toolbox app

track 📐toolbox

Load, select, convert, and edit GPX/KML tracks and waypoints in the browser.

Files

  • Upload files (u) — GPX, KML, ZIP, or KMZ (multiple). Tracks (LineString) and waypoints (Point). Max size per file applies; oversized files are rejected with a toast.
  • GPX / KML — Download the current selection. LineStrings: one file, or ZIP if several. Points: see Points below (never mixed into the same XML as a LineString).
  • Remove — Delete selected features.
  • Clear all — Remove every loaded feature.

Selection & metadata

  • Click a feature on the map or in the list to multi-select; click again to deselect.
  • Name / Description always edit the last selected feature. Selection count is shown above the list.
  • Selected lines use the highlight style; points use a larger circle marker (also in 3D).
  • Search — Fuzzy-match loaded tracks (name / description / source; always listed first), then OSM Nominatim places. Enter / click selects a track or flies to a place.

Map

  • 2D Leaflet map with locate control and the usual base layers from the shared map CSS.
  • Toggle 3D terrain (Mapbox) via the map control; tracks/points sync into 3D. Edit mode forces 2D.

Points

  • Add — Map control (point + crosshair), also p. Click the map to drop Point features into the list (named Point N). Stays on for multiple clicks; Esc, p again, or the control exits. Mutually exclusive with Digitize and edit; 2D-only.
  • Each click is its own list item (select / name / edit separately).
  • Export — On GPX/KML download, all selected Points are written into one points.gpx or points.kml (many waypoints in a single file). Points and LineStrings are never mixed in the same document. If the selection also includes LineStrings, you get a ZIP: points.* plus one file per line.

Digitize (BRouter)

Separate map control (route icon). Place waypoints, snap via BRouter (profiles / straight legs as in legacy_trails). The list button / save dialog adds a LineString to Tracks (no GPX download from digitize — export from the panel). Digitize is 2D-only; feature pick is blocked while active. Override endpoint with ?brouter=….

  • Clear window = BRouter coverage; grey veil outside (Alps AT–CH–IT; lon 5–20°, lat 40–50°).
  • Stations farther than ~75 km crow-flies are refused (too slow / heavy for the router).
  • Esc while a leg is routing cancels that request and keeps a straight chord between the last stations.
  • r — Toggle Digitize. Second press exits (cancels in-flight leg like Esc, leaves waypoints/route on the map; no save prompt).
  • Ctrl+Z / Ctrl+Y — Undo / redo last station edit (add, move, insert, clear).

Shortcuts

Desktop / keyboard only — phones and tablets have no shortcut keys (and no k cheat sheet). Use the on-map controls and touch gestures instead.

On a keyboard, press k to show / hide the on-map cheat sheet and shortcut badges. Same list:

  • k — Show / hide shortcut badges + cheat sheet
  • + / - — Zoom in / out
  • u — Upload files
  • p — Add Point on / off
  • r — Digitize on / off (off keeps route on the map)
  • l — GPS locate on / off
  • 3 — 3D terrain on / off
  • Esc — Cancel in-flight Digitize leg / exit Point tool
  • e — Edit when exactly one feature is selected
  • Ctrl+A — Select all tracks; again deselects all
  • n s t d f — Edit tools (f = df; t toggles trim)
  • ← / → — After a LineString edit (n/s/t/d), step the last-touched vertex up/downstream and pan the map
  • Enter — Save edit · Esc — Discard edit
  • Ctrl+Z / Ctrl+Y — Undo / redo (edit session or Digitize stations)

Edit geometry

Open the edit toolbox with a right-click on a feature (desktop), or a long-press on mobile (browser fires the same context-menu event). On a keyboard you can also press e when exactly one feature is selected. There is no separate edit button. One edit session per start; tools switch without leaving the session.

  • Save button (or Enter) — Save changes.
  • × (or Esc) — Discard (restores the session snapshot).
  • ↶ / ↷ buttons (or Ctrl+Z / Ctrl+Y) — Undo / redo within the session. Buttons are for mobile; shortcut badges show with k on desktop.
  • After n / s / t_ / _t / d on a LineString, the last touched vertex is remembered (cyan outline). ← / → step along the track and pan/zoom the map (≥ zoom 15). Cleared when the session ends or you switch to another session feature.
  • Tool buttons on the edit panel (or n / s / d / f on keyboard; f = df; t toggles t_ ↔ _t). t_ = trim before, _t = trim after. Points: n, d, df only.
  • Right-click / long-press another session feature (e.g. after a split) to switch the active target. Doing that on a non-session feature asks to discard and start a new session.

Edit tools

Vertex markers stay visible in every tool (node pane above the line). Letter = active tool. Start vertex green, end vertex red. Points: n, d, df.

  • n — Node: drag vertices / Point; click the line away from vertices to insert. Elevation kept when present.
  • s — Scissor: click the line or a mid vertex to split (not start/end). Both parts stay in the session; the later part becomes active.
  • t_ — Trim before: delete everything before the click.
  • _t — Trim after: delete everything after the click.
  • d — Delete node: click a vertex to remove it, or a Point to remove that feature (min. two vertices on a line).
  • df (f) — Delete feature: click a session Point or LineString to remove it whole. Empty session closes.

Notes

  • Scissor / trim apply only to LineStrings. Cuts too close to an endpoint are ignored.
  • On LineString edit enter, vertices are chord-simplified once (~every 25 m along-track). Those nodes (plus any you add) stay for the session — no re-thinning. Discard restores the dense original; save keeps the chords.
  • Discard restores the full track list from when the session started (including undoing splits and deletes in that session).
  • Save commits the working geometry into the loaded set; then you can export as usual.
