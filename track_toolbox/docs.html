track 📐toolbox

Free browser tool to load, edit, convert and export GPX/KML tracks and waypoints. Basic GPX/KML knowledge is assumed.

Files

  • Upload files (u) — Load one or more GPX, KML, ZIP or KMZ files. Tracks and waypoints appear in the list. Very large files are refused.
  • GPX / KML — Download what you have selected.
    • Separate files (default) — each track becomes its own file (ZIP if you selected more than one).
    • Feature collection — all selected tracks go into one tracks.gpx or tracks.kml.
    • Waypoints always go into one points file (never mixed with tracks in the same file). If you selected both tracks and waypoints, you get a ZIP with both.
  • Remove — Delete the selected items.
  • Clear all — Remove everything from the list.

Selecting & renaming

  • Click a track or waypoint on the map or in the list to select it. Click again to deselect. You can select several at once.
  • Shift+drag on the map draws a rectangle and adds every visible track or waypoint that is inside it or crosses it to the current selection.
  • Name and Description always edit the last item you selected.
  • Selected tracks are highlighted; selected waypoints show a larger marker.
  • Search/Filter — Type a name (or part of a name / description). Matching items stay on the map and in the list; the rest are hidden for now. The dropdown also suggests places from OpenStreetMap — pick one to fly there. Clear the field to show everything again. Your selection is kept while you filter.

Map

  • Normal 2D map with zoom, GPS locate, and base-map choices.
  • Use the cube control for a 3D terrain view. Your tracks and waypoints show there too. Editing always switches back to 2D.

Waypoints (points)

  • Use the point control on the map (or p), then click the map to add waypoints. They show up in the list as Point 1, Point 2, …
  • Stay in point mode for several clicks. Exit with Esc, p again, or the control. Not available while Digitize or Edit is on (2D only).
  • Each waypoint is its own list item — you can rename or edit it separately.
  • When you download, all selected waypoints become one points.gpx / points.kml.

Digitize (draw a route)

Use the route control on the map. Click to place stations; the path between them is routed (or drawn straight, depending on the pen mode). When you save, the route is added to your track list — then export it with GPX/KML from the panel as usual. Digitize is 2D only.

  • Routing works inside the clear map window (Alps area). Outside that, the map is greyed out.
  • Stations more than about 25 km apart are not allowed (too heavy for the router).
  • Esc while a leg is calculating cancels that leg and keeps a straight line instead.
  • r — Turn Digitize on/off. Turning off leaves your route on the map (no save prompt).
  • Ctrl+Z / Ctrl+Y — Undo / redo station changes.

Edit a track or waypoint

Right-click (computer) or long-press (phone) a feature to open the edit panel. Or select exactly one item and press e. You stay in one edit session until you save or discard; you can switch tools freely.

  • Save (or Enter) — Keep your changes.
  • × (or Esc) — Discard everything from this edit session.
  • ↶ / ↷ (or Ctrl+Z / Ctrl+Y) — Undo / redo. The buttons are especially useful on mobile.
  • After you change a track node, it is marked. Use ← / → to step to the previous/next node and move the map there.
  • Right-click / long-press another piece from the same edit (e.g. after a split) to work on that piece. Doing that on a different track asks whether to discard first.

Edit tools

Nodes on the track stay visible. Activate tools with the shortcuts n, d, f, t, s. When active, the start node is marked green, the end red. The letters on the nodes indicate which tool is active. For waypoints only n, d and df apply.

n Move nodes (drag). Click the track between nodes to insert a new one. Elevation is kept when the file had it.
s Split the track at the click (not at start/end). You get two pieces; the later one becomes active.
t_ Cut off everything before the click.
_t Cut off everything after the click.
d Delete one node (or the whole waypoint if you click a point). A track needs at least two nodes.
df Delete the whole track or waypoint. If nothing is left in the session, edit closes.

Good to know

  • Split and trim only work on tracks, not on waypoints. Clicks too close to the start or end are ignored.
  • When you start editing a track, dense GPS points are thinned to about every 25 m so the nodes are usable. Discard brings back the original dense track; Save keeps the thinned version (plus your edits).
  • Discard undoes the whole edit session (including splits and deletes done in that session).
  • After Save, export with GPX/KML as usual.
