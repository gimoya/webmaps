GPX and KML on your phone

The lightest browser tool for cleaning and converting GPX and KML. Load, edit, cut, crop, reroute, export. No account, no ads, no install. Same tool on a phone: tap, long-press, on-map buttons. Tips are highly appreciated and needed to keep the tool running.

Open track toolbox

The screen

  • Portrait — the track panel sits at the top center. The map is the rest of the screen. Scroll the panel for upload, the list, and export.
  • Landscape — the panel sits at the top left so the map keeps the width.
  • The chevron in the title line hides the panel. The title and the info button stay.
  • Map buttons (zoom, GPS locate, 3D, add point, digitize) are on the map. You do not need the keyboard shortcuts. Those are for a computer; k shows them when you have a keyboard.

Fingers

  • Upload — the upload button opens the phone’s file picker. GPX, KML, KMZ, ZIP, and FIT.
  • Select — tap a track or waypoint on the map or in the list. Tap again to deselect. Several can be selected.
  • Edit — long-press a feature. The edit panel opens with the tool buttons (n move, s split, t trim, d delete, df delete the feature). Drag a node to move it. Save keeps the edit. × discards it. ↶ / ↷ are the undo and redo buttons — that is the mobile path; you do not need Ctrl+Z.
  • Points — the point control, then tap the map once per waypoint.
  • Find yourself — the locate control uses the phone’s GPS.

The router, on a phone

Digitize is the same control. Turn it on, tap stations, BRouter fills the path (MTB, trekking, or hiking, inside the Alps window). ↶ undoes the last station and ↷ does it again. Save puts the route in the list. Router guide.

Help without losing the tracks

The info button opens the docs in a sheet over the map. Close it and you are back on the same tracks. Leaving the page or refreshing the browser still clears the session — the files live in the page, not on a server.

Export

Select what you want, then GPX or KML. The browser downloads the file to the phone. Waypoints stay in their own points file.
