GPX to KML & KML to GPX — convert and edit

Most converters only flip the format. track toolbox lets you convert and edit in one place: upload GPX, KML, KMZ or ZIP, multi-select, clean geometry, then export the format your device or Google Maps needs.

Open track toolbox

Export that stays disciplined

  • Separate files — each track its own file (ZIP if many).
  • Feature collection — selected tracks in one tracks.gpx / tracks.kml.
  • Waypoints always go to a points file — never mixed into the tracks file. Mixed selection → ZIP with both.

When conversion is only half the job

Tourism packages, event courses, and Maps imports fail when the file is a junk drawer. Convert after you’ve selected and cleaned — or convert first, then trim. Same toolbox either way.
