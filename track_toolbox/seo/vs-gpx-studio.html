track toolbox vs gpx.studio

gpx.studio is the main peer in free browser GPX editing — a full workshop. track toolbox is a surgical toolbox: faster when the job is multi-select → cut → export (especially with KML/KMZ and Google Maps/Earth).

Open track toolbox

Pick by job

  • Use gpx.studio when you need deep file surgery: elevation refresh, time data, reverse/round-trip helpers, merge/connect traces, POI icons, long single-route polish.
  • Use track toolbox when you need selection-first cleanup: many features, Shift+box select, trim/scissor session with undo, GPX↔KML/KMZ, tracks vs points never mixed, clean set for Maps/Earth re-import.

Side by side (honest)

  • Mindshare — studio wins. We’re not pretending otherwise.
  • Multi-feature batch ops — toolbox is built for that loop.
  • KML / KMZ — first-class in toolbox; studio is GPX-first.
  • Google Maps / Earth cleanup ↔ re-import — flagship toolbox use case.
  • Elevation / time / merge — studio goes deeper.
  • Digitize — both can route; toolbox BRouter window is Alps-strong (regional), not a world planner claim.

Bottom line

Not a clone war. If your workflow is “select → cut → export” more often than “rebuild a timed elevation route,” start with track toolbox. Keep studio for the workshop days.
