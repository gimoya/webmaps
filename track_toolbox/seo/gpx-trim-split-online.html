Trim & split GPX online

Bad GPS loops, cool-down tails, wrong forks, dense breadcrumbs you can’t drag — track toolbox is a surgical editor for that: select, cut, save, export. No install, no account; files stay in your browser.

Open track toolbox

Edit tools that match the job

  • Node (n) — drag / insert vertices
  • Scissor (s) — split a track at a click
  • Trim before / after (t_ / _t) — drop everything before or after a point
  • Delete node (d) / delete feature (df)
  • Undo / redo — session history; Save or Esc to keep or discard

Right-click (or long-press on phone) a feature to enter edit, or select one item and press e. Full detail in the docs.

Multi-select first, then operate

Click to toggle selection, Shift+drag to box-add, Ctrl+A / Ctrl+D for all / none. Filter by name without losing selection. Export only what you selected — separate files or one collection; waypoints in a points file.

Who this helps

Athletes and coaches cleaning device dumps, event managers cutting courses into stages, trail builders splitting GPS surveys, tourism teams shipping only the productized line.
